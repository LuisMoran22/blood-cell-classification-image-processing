# MEXT Interview Notes

## How to Explain This Project

This was a university biomedical engineering project focused on automated blood cell analysis from microscopy images. The main goal was to use image processing and machine learning to support the detection and classification of white blood cells in blood smear images.

The project is important because blood smear analysis is a common medical procedure, but manual analysis can be time-consuming and dependent on expert interpretation. Automated systems can help standardize preliminary analysis and support clinical decision-making.

## Technical Explanation

The workflow included image preprocessing, cell localization, classification, and evaluation. The available results show four-class leukocyte classification into neutrophils, eosinophils, monocytes, and lymphocytes. A second experiment classified cells into mononuclear and polynuclear groups.

The performance was evaluated using classification reports and confusion matrices. The available four-class experiments reached representative accuracies around 0.83–0.84, while the binary mononuclear/polynuclear classification showed higher performance in several runs.

## Connection to Future Research

This project connects directly with future research in artificial intelligence for healthcare because it demonstrates experience with biomedical data, medical image analysis, and model evaluation. It also provides a foundation for more advanced research involving deep learning, multimodal medical data, and clinically useful AI systems.

## Honest Limitation to Mention

The project was developed as an undergraduate/university project, so its limitations include dataset size, reproducibility, and the need for stronger validation. A future version should use a larger dataset, robust train-validation-test separation, and more advanced deep learning architectures.
