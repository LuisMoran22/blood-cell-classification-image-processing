# Dataset Notes

The uploaded dataset was verified as the Paul Mooney-style `dataset2-master` blood cell dataset with 4 classes:

- EOSINOPHIL
- LYMPHOCYTE
- MONOCYTE
- NEUTROPHIL

The code uses `TRAIN` and `TEST` folders. `TEST_SIMPLE` is detected in the dataset summary but is not used for training by default.

Do not upload the full dataset to GitHub unless redistribution is clearly allowed. Link to the original dataset source instead.
