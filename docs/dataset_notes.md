# Dataset Notes

This project is adapted for the Blood Cell Images dataset by Paul Mooney.

The verified local dataset contains:

| Split | Eosinophil | Lymphocyte | Monocyte | Neutrophil | Total |
|---|---:|---:|---:|---:|---:|
| Train | 2497 | 2483 | 2478 | 2499 | 9957 |
| Test | 623 | 620 | 620 | 624 | 2487 |
| Total | 3120 | 3103 | 3098 | 3123 | 12444 |

The dataset should be downloaded from the original public source and placed locally inside the `data/` folder.

Do not upload the full dataset to GitHub unless redistribution is explicitly allowed.
