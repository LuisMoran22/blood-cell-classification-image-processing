# Project Summary

## Short Description

Automated blood cell classification project using biomedical image processing and machine learning. The system analyzed blood smear microscopy images and produced classification outputs for leukocyte categories such as neutrophils, eosinophils, monocytes, and lymphocytes. The project also included a binary classification task separating mononuclear and polynuclear cells.

## Resume / CV Version

Developed a biomedical image processing project for automated blood cell analysis, including preprocessing, cell detection, leukocyte classification, and evaluation using confusion matrices and classification metrics.

## Stronger CV Version

Developed a biomedical image analysis system for automated blood cell detection and classification from microscopy images. The project included image preprocessing, cell localization, four-class leukocyte classification, mononuclear/polynuclear classification, and model evaluation using accuracy, precision, recall, F1-score, and confusion matrices.

## LinkedIn / GitHub Description

University biomedical engineering project focused on AI-assisted blood smear image analysis. The project explored automated cell detection and classification using image processing and machine learning techniques, with evaluation through classification reports and confusion matrices.
